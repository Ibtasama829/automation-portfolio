# Automation portfolio

Business automations I build for startups and small businesses, using n8n, AI and the tools teams already use (Google Workspace, Gmail, Sheets).

Each project folder has:
- `README.md`: the problem, the solution, the tools and the test results
- `workflow.json`: the n8n workflow, ready to import (no secrets; credentials are named references only)
- `sample-data.csv`: the fictional test data used in the demo
